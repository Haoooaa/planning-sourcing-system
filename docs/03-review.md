# 03 — 评审（Review）

## 3.1 评审目的

在投入上线与对外讲解前，确认：**范围正确、原型可演示、风险已知、文档可交接**。

## 3.2 评审类型与参与人

| 评审 | 时机 | 参与 | 关注点 |
|------|------|------|--------|
| 需求评审 | PRD 初稿后 | 产品 + 开发 | 范围 / 非目标是否清晰 |
| 原型评审 | MVP 可点后 | 产品 + 开发 + 可选干系人 | 演示路径、文案、数据可信度 |
| 上线评审 | 发 Pages 前 | 开发 + 产品 | 构建、路由、链接、许可证与出处 |

## 3.3 原型评审清单

### 产品与范围

- [ ] 一句话定位能讲清（演示原型 ≠ 生产 WMS）
- [ ] In / Out of Scope 无歧义
- [ ] 未混入已否决的行业映射（如汽配 OE/齐套）

### 体验与演示

- [ ] 免登录进入 Home
- [ ] Inventory 筛选可用
- [ ] Reorder Plan → Tasks → Files 闭环通
- [ ] PO / Orders 状态 Tag 可读
- [ ] 英文原字段可接受（或已说明为何保留）

### 工程与合规

- [ ] ZavaShop 来源已在 README / SOURCE 标明
- [ ] 无真实客户隐私数据
- [ ] `npm start` 可复现
- [ ] hash 路由策略已确认（利于 Pages）
