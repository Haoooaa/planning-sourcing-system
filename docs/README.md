# ZavaShop SCM Demo — 产品文档索引

本目录按 **需求分析 → PRD → 评审 → 上线 → 迭代** 组织，对应本仓库静态供应链演示原型。

## 网页图文版（推荐）

本地运行后打开：**http://localhost:8000/#/guide**

或侧栏「产品文档」/ 首页「打开产品文档（图文）」。

| 阶段 | 文档 | 产出物 |
|------|------|--------|
| 1. 需求分析 | [01-requirements.md](./01-requirements.md) | 背景、干系人、问题、范围、非目标 |
| 2. PRD | [02-prd.md](./02-prd.md) | 目标、用户故事、功能清单、验收标准 |
| 3. 评审 | [03-review.md](./03-review.md) | 评审清单、结论、风险与待决 |
| 4. 上线 | [04-launch.md](./04-launch.md) | 构建、GitHub Pages、检查表 |
| 5. 迭代 | [05-iteration.md](./05-iteration.md) | 路线图、反馈收集、版本策略 |
| 附录：原型说明 | [06-prototype.md](./06-prototype.md) | 信息架构、页面、数据来源 |
